# tekiwa-web

Landing de **Tekiwa**, la herramienta de operacion para vendedores de Mercado Libre.

Sitio estatico servido por GitHub Pages. El dominio `tekiwa.com` se apuntara aqui
cuando su DNS deje de estar administrado por Tiendanube (ver memoria de dominios).

Mientras tanto vive en la URL de Pages del repositorio.
